Query your database from inside the doc

Define a named SQL query as a source block against any attached database, right in the editor. The result lives in the page — a live card you can edit and reference from anywhere below it.

Live values

Numbers that update with your data

Drop a single result inline with ${{source.column}}. "We currently track 30 vendors" stays true because it is the query — recomputed from the database, not copy-pasted.

Embed a database, table, or row

Paste a Datasette link and it becomes a rich embed — an inline pill or a full block card — rendered live against Datasette's JSON API. Other plugins can supply their own embeds too, for anything from maps to spreadsheets.

@mention someone inside a task item and it's assigned to them; add a date and it's the due date. No separate task tracker — the dedicated TODOs page collects everyone's assigned work across every paper they can see, bucketed by due date.

Getting started

Papers are just data

Your documents live in SQLite

No separate datastore. Every paper is rows in Datasette's internal database — an append-only step log plus snapshots — so you can query, back up, and pipe your documents like any other table.

That's also why a paper can read your data: it's all the same Datasette. Everything is also reachable over a JSON API and a small datasette paper CLI for scripting exports, backups and a git-mirror of your papers as markdown, all without a server running.

Learn how papers are stored  ·  See the CLI 
-- the tables a paper lives in
_datasette_paper_doc       -- one row per paper
_datasette_paper_step      -- append-only edits
_datasette_paper_snapshot  -- periodic full docs
_datasette_paper_share     -- access grants

-- so this just works:
select name, created_by from _datasette_paper_doc;

Get started

Install it into your Datasette

datasette install datasette-paper

Pass --internal papers.db to persist papers across restarts, and grant the four datasette-paper-* permissions. No user database required.

See the installation and configuration guides for details.
