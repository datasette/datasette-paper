# Keyboard shortcuts

`Mod` is `Cmd` on macOS and `Ctrl` elsewhere. These are the primary chords
shown as hints in the toolbar, Insert and slash menus — each one is
verified against the keymap that actually binds it.

| Shortcut | Action |
|---|---|
| `Mod-z` | Undo |
| `Shift-Mod-z` | Redo |
| `Mod-b` | Bold |
| `Mod-i` | Italic |
| `` Mod-` `` | Inline code |
| `Mod-Shift-x` | Strikethrough |
| `Mod-Shift-h` | Highlight (repeats the last-used color) |
| `Mod-k` | Link |
| `Shift-Ctrl-0` | Text (paragraph) |
| `Shift-Ctrl-1` / `2` / `3` | Heading 1 / 2 / 3 |
| `Ctrl->` | Blockquote |
| `Shift-Ctrl-\` | Code block |
| `Shift-Ctrl-8` | Bullet list |
| `Shift-Ctrl-9` | Numbered list |
| `Mod-Shift-7` | Task list |
| `Mod-]` / `Mod-[` | Indent / outdent |
| `Mod-;` | Insert today's date |
| `Mod-Shift-;` | Insert tomorrow's date |
| `Mod-_` | Divider |
| `Mod-Enter` | Run query (inside a `source` / SQL block) |

See [Editor](editor.md), [Slash menu](slash-menu.md) and
[Sources and values](sources-and-values.md) for what each of these inserts
or formats.
