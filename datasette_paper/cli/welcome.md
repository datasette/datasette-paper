# Welcome to datasette-paper

**paper** is a collaborative document editor, built as a plugin for Datasette. Docs are stored right alongside your data, and edits sync live between anyone with access — no separate server, no separate account system.

Try checking this box:

- [ ] check me off

A few things worth knowing:

- Text supports the usual *emphasis*, **bold**, and `inline code`.
- Checklists like the one above are real tasks — every one you write anywhere shows up on the [todos](/-/paper/todos) page, grouped by who it's assigned to.
- Tags such as [#welcome](paper:/tag/welcome) are just words with a `#` in front of them. Click one to see every doc that mentions it.
- Docs export straight back out to markdown — the same format this page is written in — from the share menu.

A short table, for good measure:

| Feature | Where to find it |
| --- | --- |
| Todos | `/-/paper/todos` |
| Tags | click any `#tag` |
| Markdown export | doc menu → Export |

> Sharing is backed by `datasette-acl`: whoever creates a doc is its Manager, and access for anyone else is a deliberate grant — nothing is visible by accident.
